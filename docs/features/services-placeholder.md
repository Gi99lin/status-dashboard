# Раздел «Сервисы» (заглушка)

## Назначение
Пункт меню «Сервисы» уже доступен, но содержимого пока нет: раздел показывает заглушку, чтобы было
видно, что функция запланирована, а не сломана.

## Пользователи и доступ
- Любой, кто открыл дашборд; ролей нет.

## Точки входа
- Пункт верхнего меню «Сервисы».

## Основной сценарий
1. Пользователь нажимает «Сервисы» → в основной области появляется панель с заголовком «Сервисы»
   и строкой «Скоро».
2. Топбар остаётся на месте, пункт «Сервисы» подсвечен как активный.
3. Пользователь возвращается на другой раздел → его содержимое отображается как обычно.

## Правила и ограничения
- Заглушка не обращается к API и не показывает данных.
- Пункт «Сервисы» кликабелен (в отличие от «CI / CD», который помечен как недоступный).

## Ошибки и крайние случаи
- Отдельных состояний ошибки или загрузки у раздела нет.

## Данные
