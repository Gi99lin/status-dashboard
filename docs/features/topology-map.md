# Интерактивная топология стека

## Назначение
Показывает, из чего состоит хост и как части связаны: группы сервисов с их контейнерами, виртуальные
машины, внешние точки входа и потоки между ними. Нужна, чтобы увидеть маршрут трафика и найти узел,
который выбивается из общей картины.

## Пользователи и доступ
- Любой, кто открыл дашборд; ролей нет.

## Точки входа
- Раздел «Карта», блок под заголовком «Топология стека».

## Основной сценарий
1. Пользователь открывает раздел «Карта» → карта отрисовывается целиком и масштабируется так, чтобы
   все узлы поместились в видимую область.
2. Узел группы показывает метку типа («SVC»), имя группы, её сети и список контейнеров с технологией
   и объёмом памяти.
3. Связи между узлами нарисованы линиями разных цветов: зелёная — трафик, синяя — удалённый доступ,
   фиолетовая — мониторинг. Подпись под картой повторяет эту легенду.
4. Пользователь тянет узел мышью → узел перемещается, связи перерисовываются.
5. Пользователь пользуется колесом мыши или кнопками управления в углу карты → карта масштабируется;
   доступны приближение, отдаление и возврат к общему виду.
6. Мини-карта в углу показывает положение видимой области относительно всей схемы.

## Альтернативные сценарии
- Узел без связей → отображается отдельно, вне потоков.
- Контейнер в нескольких сетях → у его группы перечислены все сети.

## Правила и ограничения
- Масштаб ограничен снизу (карту нельзя уменьшить бесконечно); при открытии раздела карта всегда
  подгоняется под содержимое с небольшим отступом.
- Позиции узлов, сдвинутых пользователем, действуют до перезагрузки страницы и не сохраняются.
- Цвет индикатора узла отражает статус: работает, idle, упал — та же легенда, что над картой.
- Логотип библиотеки визуализации на карте не показывается.

## Ошибки и крайние случаи
- Топология не загрузилась → над картой красная строка «ошибка загрузки: {текст}», область карты
  остаётся пустой.
- Поток обновлений оборван → состояние над картой меняется на «нет связи», последняя схема остаётся
  на экране.

## Данные
- Источник: `GET /api/topology` — хост, группы сервисов с контейнерами, отдельные узлы, сети и связи.
- Demo-набор: группы вида `docflow`, `qa-runner`, внешние точки `internet` и `nginx`, VM через
  Guacamole и узлы мониторинга Netdata.
