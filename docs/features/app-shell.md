# Оболочка приложения: топбар, навигация, период

## Назначение
Единая верхняя панель на всех экранах: бренд, переключение разделов, состояние хоста и выбор периода
телеметрии. Приложение одностраничное — разделы меняются без перезагрузки и без смены адреса.

## Пользователи и доступ
- Любой, кто открыл дашборд; ролей нет.
- Если задан `DASHBOARD_PASS`, топбар появляется только после входа (см. `auth-login`).

## Точки входа
- Корневой адрес `/`. По умолчанию открыт раздел «Карта», период — «1ч».

## Основной сценарий
1. Пользователь открывает дашборд → в левой части топбара показан бренд (`stack.map`, в demo-сборке —
   `demo.map`), в центре — меню, справа — плашка хоста и переключатель периода.
2. Меню содержит пункты: «Карта», «Контейнеры», «Сети», «Сервисы» и неактивный пункт «CI / CD» с
   меткой «скоро».
3. Активный пункт подсвечен; у пункта «Карта» слева стоит зелёный индикатор.
4. Пользователь нажимает пункт меню → в основной области открывается соответствующий раздел, адрес
   страницы не меняется, страница не перезагружается.
5. Плашка хоста показывает пульсирующий зелёный индикатор, имя хоста и «online {аптайм}»
   (в demo-наборе — «gigglin-server · online 40д»).
6. Переключатель периода содержит кнопки «10м», «1ч», «6ч», «24ч»; активна одна. Выбор периода меняет
   подпись и данные графика телеметрии на разделе «Карта».

## Альтернативные сценарии
- Пользователь нажимает «CI / CD» → ничего не происходит: пункт помечен как недоступный.
- Пользователь нажимает пункт активного раздела ещё раз → раздел остаётся прежним.
- Аптайм хоста неизвестен → в плашке выводится «online —».

## Правила и ограничения
- Разделов ровно четыре: карта, контейнеры, сети, сервисы. Порядок пунктов фиксирован.
- Период по умолчанию — «1ч»; выбранный период сохраняется при переключении разделов в пределах сессии
  и сбрасывается после перезагрузки страницы.
- Ссылки меню содержат якоря вида `#map`, но переход по якорю подавляется: адресная строка не меняется.

## Ошибки и крайние случаи
- Данные топологии не загрузились → плашка хоста показывает пустое имя и «online —», меню и период
  остаются рабочими.
- Пока идёт проверка авторизации, интерфейс не отрисовывается (пустой экран).

## Данные
- Имя хоста и аптайм берутся из топологии (`GET /api/topology`).
- Demo-набор: хост «gigglin-server», аптайм «40д».
