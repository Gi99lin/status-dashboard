# Вход по паролю

## Назначение
Закрывает дашборд от посторонних одним общим паролем. Функция необязательна: если пароль в настройках
сервера не задан, дашборд открыт всем, у кого есть адрес.

## Пользователи и доступ
- Один общий пароль на всех, ролей и учётных записей нет.
- Пароль задаётся на сервере переменной `DASHBOARD_PASS`. Если она пустая — включён открытый режим.

## Точки входа
- Любой адрес дашборда, когда действующей сессии нет: вместо интерфейса показывается экран входа.

## Основной сценарий
1. Пользователь открывает дашборд без сессии → показывается экран входа: бренд, подпись «вход»,
   поле пароля с подсказкой «пароль» и кнопка «войти».
2. Фокус стоит в поле пароля; вводимые символы скрыты.
3. Пользователь вводит верный пароль и нажимает «войти» → экран входа исчезает, открывается раздел
   «Карта», сессия сохраняется в cookie.
4. При следующем открытии дашборда с действующей сессией экран входа не показывается.

## Альтернативные сценарии
- Пользователь нажимает «войти» с пустым полем → ничего не происходит, запрос не отправляется.
- Пока идёт проверка пароля, кнопка недоступна и показывает «...».
- Пока проверяется наличие сессии, интерфейс не отрисовывается (пустой экран).

## Правила и ограничения
- Пароль проверяется на сервере; клиент хранит только cookie сессии.
- Без сессии закрыты все запросы `/api/*`, кроме проверки здоровья, входа и проверки сессии,
  а также поток живых обновлений.
- Секрет сессии задаётся на сервере и переживает перезапуск контейнера: сессии не сбрасываются.

## Ошибки и крайние случаи
- Неверный пароль → под полем появляется сообщение «Неверный пароль», пользователь остаётся на экране
  входа, поле не очищается.
- Сервер недоступен → вход не выполняется, экран входа остаётся.

## Данные
- Проверка сессии: `GET /api/auth-check`; вход: `POST /api/login` с паролем; сессия — cookie
  `dashboard_session`.
- Тестовые данные: пароль берётся из переменной окружения (в `.qa-lab.json` объявляется имя
  переменной, значение хранится в Keychain).
- В demo-режиме вход не участвует: данные берутся из встроенного набора без обращения к API.
