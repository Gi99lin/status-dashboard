# Раздел «Карта»: карточка хоста, телеметрия, метрики

## Назначение
Верхний ряд раздела «Карта» отвечает на вопрос «как себя чувствует хост прямо сейчас»: параметры
машины, загрузка ресурсов, график телеметрии за выбранный период и две сводные метрики.

## Пользователи и доступ
- Любой, кто открыл дашборд; ролей нет.

## Точки входа
- Пункт меню «Карта» (открыт по умолчанию при входе).

## Основной сценарий
1. Пользователь открывает раздел «Карта» → верхний ряд показывает три блока: карточку хоста,
   график телеметрии и две метрики.
2. Карточка хоста содержит строки: «статус» — «online · up {аптайм}», «железо» — «{N} vCPU · {M} GB»,
   «ОС» — название и версия системы, «контейнеров» — «{всего} · {активны} активны».
3. Под строками идут витал-бары «CPU», «RAM», «Диск» — значение в процентах с закрашенной полосой, и
   «Сеть» — значение в мегабитах с суффиксом «M».
4. Блок телеметрии озаглавлен «Телеметрия хоста · {период}» и рисует график за выбранный период с
   легендой рядов (CPU, RAM, Сеть).
5. Справа показаны две карточки: «Docker-сетей» с числом сетей и «Публичных URL» с числом адресов и
   подписью «· nginx».
6. Ниже верхнего ряда идёт заголовок «Топология стека» с состоянием потока данных и легендой статусов
   «работает / idle / упал», затем сама топология (см. `topology-map`).

## Альтернативные сценарии
- Пользователь меняет период в топбаре → подпись графика и его данные меняются, остальные блоки
  остаются на месте.
- Значение параметра хоста неизвестно → в строке выводится «—».

## Правила и ограничения
- Проценты CPU, RAM и Диска округляются до целых; сеть выводится как есть с суффиксом «M», полоса сети
  ограничена 100 %.
- Цвет витал-бара зависит от значения: спокойный при низкой загрузке, предупреждающий при высокой.
- Карточек метрик ровно две; дублирующие показатели (контейнеры, CPU, RAM) в отдельные плашки не
  выносятся — они уже есть в карточке хоста.
- Состояние потока: «живая · поток = трафик · кольцо = нагрузка» зелёным, когда есть соединение,
  и «нет связи» приглушённым, когда соединения нет.

## Ошибки и крайние случаи
- Ошибка загрузки топологии → вместо состояния потока выводится красное «ошибка загрузки: {текст}».
- Соединение с сервером потеряно → состояние меняется на «нет связи», последние данные остаются
  на экране.

## Данные
- Источник: `GET /api/topology` (хост, телеметрия, группы сервисов, сети) и живой поток обновлений.
- Demo-набор: хост «gigglin-server», «12 vCPU · 30 GB», ОС «Ubuntu 24.04.4 LTS (Noble Numbat)»,
  «контейнеров 49 · 47 активны», CPU 18 %, RAM 38 %, Диск 61 %, Сеть 1.2M, «Docker-сетей 19»,
  «Публичных URL 8 · nginx».
- Известное расхождение: карточка хоста в demo-наборе считает 49 контейнеров и 19 сетей, а разделы
  «Контейнеры» и «Сети» — 48 и 15; числа приходят из разных источников и не сверяются между собой.
